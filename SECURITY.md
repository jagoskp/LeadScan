# Security Policy

## Supported Versions

We actively support and apply security patches to the following versions of LeadScan AI:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of LeadScan AI seriously. If you find a security vulnerability, please do NOT open a public GitHub issue. Instead, report it privately.

Please report security issues to: **security@leadscan.ai**

Please include the following information in your report:
- Component/Service affected (e.g. `services/ocr-engine`, `apps/web`)
- Detailed steps to reproduce the vulnerability
- Any potential impact or exploits possible
- Recommended fix or mitigation, if known

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to coordinate a disclosure and patch timeline.
