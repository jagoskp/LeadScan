# Changelog

All notable changes to the **LeadScan AI** project will be documented in this file.

## [0.1.0] - 2026-07-30

### Added
- Initial enterprise monorepo folder structure.
- Root configurations for TypeScript, Python, ESLint, Prettier, Ruff, MyPy, and EditorConfig.
- Issue and Pull Request templates, CODEOWNERS rules.
- Placeholder structure for Web, Admin, and Mobile applications.
- Placeholder structure for API, AI Engine, OCR Engine, and Worker services.
- Placeholder structure for Shared, SDK, Config, and UI shared packages.
- Infrastructure and DevOps directory foundation.
